# Sécurité et publication publique

- Ne jamais committer secrets, clés API, tokens OAuth, cookies, données client ou fichiers .env.
- Inspecter les archives et scripts avant publication.
- Garder les ressources privées dans un dépôt séparé.
- Respecter la licence des dépôts tiers ; ne pas republier du code sans autorisation.
- Documenter dépendances, versions, limites et statut de test.
