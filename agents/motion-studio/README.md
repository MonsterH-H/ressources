# Agents — Motion Studio

Rôles spécialisés définis dans le pack Motion Studio Core :

| Agent | Responsabilité |
|---|---|
| motion-director | Vision créative, rythme et cohérence de production |
| motion-designer | Animation 2D, typographie, transitions et systèmes graphiques |
| storyboard-artist | Séquences, plans, timing et intentions visuelles |
| 3d-artist | Objets, scènes, matériaux, éclairage et rendu 3D |
| audio-localization | Voix, montage sonore, transcription et adaptation multilingue |
| video-pipeline-engineer | Orchestration Remotion, HyperFrames, FFmpeg, Three.js et Blender |
| video-qa | Lisibilité, continuité, audio, droits et exports |
| art-director | Langage visuel, références, palette et styleframes |

Cet index ne remplace pas les fichiers de rôle détaillés du package source.
