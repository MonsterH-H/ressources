# Motion Studio Core — Professional Video Producer

Plugin Claude Code de production vidéo de bout en bout : brief, direction artistique, script, storyboard, gestion des assets, montage, motion design, 2D/3D, audio, voix, sous-titres, localisation, génération vidéo IA, rendu et contrôle qualité.

## Commandes
- /motion-studio:make-video — pipeline complet
- /motion-studio:edit-video — montage et révision
- /motion-studio:storyboard — script et storyboard
- /motion-studio:art-direction — direction artistique
- /motion-studio:motion-design — animation 2D, typographie et infographies
- /motion-studio:3d-scene — scène 3D
- /motion-studio:voice-and-captions — voix et sous-titres
- /motion-studio:localize-video — adaptation multilingue
- /motion-studio:ai-video — génération de plans par IA
- /motion-studio:render-qa — contrôle qualité et export
- /motion-studio:setup-check — diagnostic environnement

## Stack
HyperFrames, HTML/CSS/SVG, GSAP, Remotion, FFmpeg/FFprobe, Three.js, React Three Fiber, Blender et outils de transcription. Les fournisseurs IA/voix nécessitent leurs comptes, clés et crédits.

## Installation Windows
Depuis le dossier du package extrait :

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\\install.ps1
```
Redémarrer Claude Code, puis lancer /motion-studio:setup-check.

## Agents
Motion director, motion designer, storyboard artist, 3D artist, audio/localization specialist, video pipeline engineer, video QA et art director. Voir agents/motion-studio/README.md.

## Limites
Aucun rendu premium ni prix commercial n’est garanti automatiquement. Vérifier les droits des médias et obtenir l’accord avant tout appel payant ou transfert vers un service tiers.

Statut de synchronisation : la documentation et les inventaires sont publiés ici. Les fichiers sources individuels et archives binaires du package local ne sont pas encore tous synchronisés.
